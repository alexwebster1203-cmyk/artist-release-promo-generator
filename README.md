# Artist Release Promo Generator

A lightweight web app that generates platform-specific promotional copy for music releases.  
Built with independent labels and artists in mind to streamline release-day marketing.

## 🎯 Purpose

Music releases require different messaging across platforms — Instagram, X, email newsletters, and press.  
This tool helps marketing teams and artists quickly generate tailored copy while maintaining a consistent tone.

## ✨ Features

- Generate:
  - Instagram captions
  - X / Threads captions (character-aware)
  - Email newsletter blurbs
  - Short press bio paragraphs
- Tone selector (Hype / Emotional / Minimal)
- Simple, clean interface
- Copy-to-clipboard functionality
- Mobile-friendly design

## 🛠 Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- OpenAI API
- Deployed on Vercel
